## Featured Projects

### [ecommerce-ai-agents](https://github.com/GuiSales21/ecommerce-ai-agents)
Automated customer support for an e-commerce store, powered by **5 specialized AI agents**
orchestrated with **LangGraph** and a vector knowledge base (**RAG** with ChromaDB).
Microservices architecture: FastAPI + PostgreSQL for the store, an agent backend, and a
Streamlit storefront — all orchestrated with Docker Compose.

`LangGraph` · `LangChain` · `RAG` · `ChromaDB` · `FastAPI` · `PostgreSQL` · `Streamlit` · `Docker Compose`

### [churn-prediction](https://github.com/GuiSales21/churn-prediction)
End-to-end machine learning system for customer churn prediction: a **Gradient Boosting**
model (AUC-ROC ≈ 0.83), a **FastAPI** REST API serving predictions, and a **Streamlit**
web app for single and batch scoring — containerized in layers with Docker Compose.

`scikit-learn` · `pandas` · `FastAPI` · `Streamlit` · `Docker Compose` · `pytest`
